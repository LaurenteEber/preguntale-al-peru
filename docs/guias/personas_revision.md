# Personas para la revisión de usuario

Se usan para revisar si una respuesta se entiende bien (S1-09 y siguientes). Para cada respuesta se anota la **lectura probable** de cada persona, si es correcta y la frase que la causa.

| Persona | Qué busca | Riesgo típico de mala lectura |
|---|---|---|
| **Madre o padre** (de una región con mucha anemia, p. ej. Huancavelica o Puno) | Saber si su hija o hijo está en riesgo y qué hacer | Leer la confianza («alta», el antiguo «verde») como si la situación estuviera bien; tomar una cifra de establecimientos como la de todos los niños |
| **Periodista** | Un titular con una cifra y un cambio | Comparar cifras con formas de medir distintas o de fuentes distintas; convertir «sin cambio claro» en «bajó» o «subió» |
| **Regidor o funcionario local** | Una cifra para un informe o para decidir gasto | No saber qué cifra usar si hay dos; leer el gasto con sede en un lugar como todo el gasto en ese lugar; atribuir causas |
| **Estudiante o docente** | Entender y verificar | No poder comprobar una afirmación porque falta la cifra con la que se compara; confundir la unidad (niños, hogares, personas) |

**Gravedad:** bloqueante = la lectura natural es falsa · alto = una persona probable lo entiende mal · medio = confunde, pero el texto lo aclara · bajo = estilo.

El texto de las respuestas se juzga contra el [contrato de respuesta](../especificaciones/contrato_respuesta.md).
